QUIT PROOF 🌱

Break the smoking loop. Take back control.

QUIT PROOF is an interactive smoking-cessation support tool that helps users identify triggers, navigate cravings, create a personal quit plan, and track progress.

Features

* Personalized smoking-trigger assessment
* Interactive Craving SOS tool
* Custom quit plan
* Progress dashboard and personal log
* Exportable progress records
* Privacy-conscious, browser-based data storage

How to Use

1. Open the QUIT PROOF website.
2. Complete the trigger assessment.
3. Create your personal quit plan.
4. Use Craving SOS when a craving appears.
5. Record your progress and reflect on your journey.

Privacy

Your entries are stored locally in your browser and are not sent to a QUIT PROOF server by this app. Clearing browser data may erase saved entries.

Technology

Built with HTML, CSS, and JavaScript. No installation or account is required to use the app.

Disclaimer

QUIT PROOF is a self-guided support tool, not medical treatment or a substitute for professional advice. Evidence-based treatment and support can help people quit smoking.
